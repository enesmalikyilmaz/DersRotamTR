# Agent çalışma kuralları
- Önce README ve ilgili dokümanları oku; belirsiz gereksinimi Issue'da sor.
- main'e doğrudan push/commit yapma; her görev için feature/fix dalı ve PR kullan.
- Küçük commit'ler, test kanıtı ve açık risk açıklaması sun.
- İnsan onayı olmadan merge veya deploy yapma.
- Secret, token ve kişisel veri commit etme.
- Her kullanıcı kaynağında sunucu tarafı ownership kontrolü yap.
- AI çıktısını kesin doğru kabul etme; kritik hesapları deterministik kodla yap.
- İki kontrollü düzeltme denemesinden sonra engeli raporla.
